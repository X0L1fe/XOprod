# Портфолио Романа Лифанова

Одностраничное портфолио на React + Vite и Django. Навыки и проекты редактируются через Django Admin.

## Стек

- Backend: Django, Django ORM, SQLite, JSON API.
- Frontend: React 18, Vite, CSS.
- Каталог иконок: Devicon. Для навыков без логотипа автоматически отображаются инициалы.
- Кастомная SVG-иконка остаётся опциональным исключением.

## Локальный запуск

Требуется Python 3.10+ и Node.js 20+.

1. Создай и активируй виртуальное окружение.
2. Установи Python-зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Примени миграции и создай администратора:

   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   ```

4. Запусти Django:

   ```bash
   python manage.py runserver
   ```

5. Открой `http://127.0.0.1:8000/`. Админка: `http://127.0.0.1:8000/admin/`.

В миграции добавляются пять проектов из актуального резюме, а существующие записи навыков сохраняются. Перед применением миграции к важной базе сделай резервную копию `db.sqlite3`.

## Frontend-разработка

Исходники React находятся в `frontend/`. Для разработки отдельного frontend-сервера:

```bash
cd frontend
npm install
npm run dev
```

Для сборки статических файлов, которые использует Django:

```bash
cd frontend
npm install
npm run build
```

Vite собирает frontend в `static/react/app.js` и `static/react/app.css`. `emptyOutDir` отключён, чтобы сборка не удаляла соседние файлы из каталога static.

Текущий `static/react/app.js` — React-версия, загружаемая через UMD CDN для запуска без предварительной сборки. После `npm run build` он заменяется самостоятельной Vite-сборкой. В production рекомендуется собирать frontend и подавать static-файлы обычным способом.

## Управление контентом

- `Админка → Навыки`: название, категория, порядок, Devicon class.
- `Админка → Проекты`: краткое и полное описание, стек (JSON-массив строк), статус, ссылка на репозиторий, избранность и порядок.
- Для основных карточек выстави `Избранный проект`. На первом плане показываются первые три избранных проекта; остальные проекты, включая дополнительные избранные, остаются в списке «Другие проекты».

## Перед публикацией

- Установи `DJANGO_SECRET_KEY` в окружении на случайное секретное значение.
- Установи `DJANGO_DEBUG=0`.
- Укажи домен в `DJANGO_ALLOWED_HOSTS`.
- Выполни `python manage.py collectstatic`.
- Настрой HTTPS и подачу `MEDIA_URL` для загружаемых SVG.
- Не публикуй `db.sqlite3`, `.env` или `media/` в репозитории.
